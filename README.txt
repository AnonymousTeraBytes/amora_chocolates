AMORA Chocolate website
========================

Files:
- index.html: page structure and copy
- style.css: responsive visual design
- script.js: mobile menu, current year, demo newsletter interaction
- assets/amora-chocolate-hero.png: generated AMORA chocolate artwork

How to run:
1. Keep the files and assets folder together.
2. Double-click index.html to open it in a browser.
3. For editing, open the folder in VS Code and change HTML/CSS/JS as needed.

Before publishing:
- Replace the demo product concepts with actual products, prices, and stock information.
- Replace hello@amorachocolate.example with a real contact email.
- Connect the newsletter form and enquiry link to a real backend or email platform.
- Confirm all product claims (e.g. ingredients or additives) before publishing.
- Google Fonts requires an internet connection; fallback fonts are included.
